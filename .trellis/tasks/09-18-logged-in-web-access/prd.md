# 登录态网页访问：长截图 + 抓取正文

## Goal

让项目能带登录态访问网页：配置了 Chrome 调试端口就接管已登录的浏览器，配置了用户数据目录就用该
profile 启动，都没配就退回现有无头截图。在此基础上提供两个 LLM 工具——整页长截图、抓取页面正文。

## Background

现有"网页长截图"工具走无头 Chrome，访问的是未登录状态。后台、个人中心、需登录的内容站未登录时
只能截到登录框或残缺内容。用户希望：**配了登录态就用登录态，没配就保持原样**。

## Requirements

### FR-1 登录态来源（按优先级只取第一个配了的）

| 优先级 | 来源 | 用户要做什么 | 特点 |
|---|---|---|---|
| 1 | 接管已开的浏览器（CDP 端点） | 用 `--remote-debugging-port` 启动 Chrome 并登录好 | 用当前会话；会新开一个可见标签页 |
| 2 | 指定用户数据目录（profile） | 准备专用目录，在里面登录一次 | 稳定、无人值守；目录不能被另一个 Chrome 同时占用 |
| 3 | 无（默认） | 什么都不做 | 现有无头模式，未登录 |

- 只有"配了"才启用；没配绝不影响现有行为（向后兼容是硬要求）。
- 高优先级配了就忽略低优先级，并在日志里说明实际用了哪一种。

### FR-2 长截图（已有能力升级）

- 保持现有行为：滚动触发懒加载 → 整页截图 → 存本地 → 返回路径/尺寸/耗时。
- 新增：登录态下截到的是登录后看到的内容。
- 返回值里说明这次用的是**登录态**还是**未登录（无头）**，便于模型转述。

### FR-3 抓取页面正文（新增工具）

- 入参 url，返回标题 + 可见正文文本。
- 超长正文按字符数截断（可配），并注明"原文 N 字，已截断到 M 字"。
- 同样走登录态；没配登录态时也能抓未登录页面。

### FR-4 可观测性与错误可读

- 日志能看出当前生效的登录态来源。
- 失败时给模型返回"人话"原因（不是异常栈），例如"连不上 9222 端口，Chrome 是不是没开调试端口"。

## Non-goals（本次不做）

- 图床 / OSS 上传（沿用现有约定，后续再说）。
- 自动登录（填账号密码、过验证码）——登录由用户在浏览器里自己完成。
- Cookie 导入导出、多账号切换。
- 用 Python / DrissionPage —— 已决定不引入 Python，改用 Playwright 的 CDP 能力达成同样效果。

## Acceptance Criteria

- [ ] 未配置登录态时，`WebScreenshotToolTest` 4 个用例仍全绿，行为与改动前一致
- [ ] 配 CDP 端点时能接管已登录 Chrome，截到/抓到的是登录后内容
- [ ] 接管模式抓完不留多余标签页，且**不会关掉用户的浏览器**
- [ ] 配 profile 目录时用它启动且登录态生效；目录不存在自动创建
- [ ] 抓正文返回标题 + 正文；超长按配置截断并注明
- [ ] 9222 没开 / profile 被占用 / 页面打不开，三种错误都返回人话，模型能转述
- [ ] 新增与修改的代码都有测试覆盖，且全部通过
