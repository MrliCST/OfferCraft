## 重构：帖子转题库管道从 browser 包拆出（domain 解耦）

- 用户要求：帖子转题库管道单独一个 domain 文件夹，不能和 browser 掺和；browser 专管浏览器基建。
- 新建 `com.example.domain.zsxq` 包，把 4 个 zsxq 专属类从 `com.example.domain.browser` 迁出
  （`git mv` 保留历史）：
  - `ZsxqCrawler`（S0 爬虫）、`ZsxqCleaner`（S1–S7 清洗器）、`ZsxqExplore`（站点侦察）、`HtmlToMarkdown`（S1 归一化）。
- browser 包只留**通用浏览器基建**：`BrowserConfig` / `BrowserSessionProperties` / `BrowserSessionProvider` /
  `CrawlThrottle` / `LoginStateCapture` / `LoginStateStore` / `PageSession` / `SiteLoginRegistry`。
- 依赖方向：zsxq（上层 domain）单向依赖 browser 基建（`LoginStateStore`、`CrawlThrottle`）；
  browser 包不反向依赖管道。ZsxqCrawler 自己 `pw.chromium().launch` + `LoginStateStore` 存档，不依赖 `BrowserSessionProvider`。
- 改动点：4 个文件 package 声明改 `zsxq`；`ZsxqCrawler`/`ZsxqExplore` 补 `import com.example.domain.browser.{LoginStateStore,CrawlThrottle}`；

- `mvn -o compile` 通过（EXIT=0）；全仓无 `com.example.domain.browser.{HtmlToMarkdown,Zsxq*}` 残留引用。
