## 知识星球 API 结构（实测，2026-09-19 17:1x）—— 方案 B 的依据

- **列表**：`GET https://api.zsxq.com/v2/groups/51121244585524/topics?scope=all&count=20`
  - 单条字段：`topic_id`(数字，官方血缘键)、`topic_uid`、`type`(talk/task)、
    `talk{owner{user_id,name}, text}`、`talk.article{title, article_id, article_url, inline_article_url}`、
    `title`、`content_voice`(语音帖)、`likes_count`、`comments_count`、`reading_count`、
    `digested`(精华)、`sticky`(置顶)、`create_time`(ISO 毫秒)。
  - **翻页**：`&end_time=<本页最后一条 create_time>`（URL-encode 冒号和 +），下一页会**重复上页最后一条**，需去重。
  - 用 Playwright 的 `context.request()` 发请求即可，自动带登录态 cookie。
- **评论**：`GET https://api.zsxq.com/v2/topics/<topic_id>/comments?count=20` → `resp_data.comments[]`（实测有效）。
- **关键限制**：`talk.text` 对**星主长文只是摘要**（实测 458 字，以 `...` 结尾），
  全文仍在 `talk.article.article_url` 指向的文章页（1.4 万字）。所以 API **不能替代**文章页取全文。
- **正文是富文本 `<e>` 标记**（不是 HTML）：`<e type="text_bold" title="%E3%80%8A..."/>`、
  `<e type="hashtag" hid=... />`、`<e type="web" href="URL-encoded"/>`、`<e type="img" ...>`（图片在正文里），
  需要写解析器（或转 HTML 后复用 HtmlToMarkdown）。
- 其他接口：`/v2/groups/<gid>/topics/sticky`（置顶）、`/v2/hashtags/<hid>/topics`（按栏目）、
  `/v2/groups/<gid>/topics/tasks`（作业）、`/v2/group/<gid>/files`。

  向量化走 `EmbeddingModel`；入库/检索准备自己写一个薄 `EmbeddingStore<TextSegment>` 适配 zsxq_chunk，
  上层用官方 `EmbeddingStoreIngestor` / `EmbeddingStoreContentRetriever`。
